# Sample Media

This directory contains sample stock images you can use to test CryptHaven's upload and encryption features.

## Contents

### 📸 `landscapes/`
- `mountain_sunset.jpg` — Alpine mountain peaks at golden hour
- `ocean_waves.jpg` — Dramatic ocean coastline at sunset
- `forest_trail.jpg` — Peaceful redwood forest trail

### 🏗️ `architecture/`
- `modern_building.jpg` — Modern glass skyscraper
- `bridge_night.jpg` — Illuminated bridge at night

### 🌿 `nature/`
- `flower_closeup.jpg` — Macro rose with morning dew
- `autumn_leaves.jpg` — Colorful autumn forest scene
- `starry_sky.jpg` — Milky Way astrophotography

## Usage

1. Start the CryptHaven server: `python crypthaven_server.py`
2. Open the web UI and set your passcode
3. Upload these images via the **📤 Upload Media** menu
4. Organize them into subfolders to test the folder management features
